# Liberalismo Comunal

Sitio oficial de Liberalismo Comunal y del escritor Pedro Jesús Guzmán Ramos.

## Desarrollo local

```bash
npm ci
npm run dev
```

## Producción

```bash
npm run build
```

El despliegue a GitHub Pages se realiza automáticamente mediante GitHub Actions al hacer push a `main`. El dominio configurado es `liberalismocomunal.org`.
